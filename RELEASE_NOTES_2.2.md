# Manga Downloader 2.2

## English

This release moves the app UI further into the macOS 26 Liquid Glass design language and ships a notarized Apple Silicon installer.

### What's new
- Updated app version to `2.2`.
- Expanded Liquid Glass treatment across service selection cards, tutorial panels, update sheets, input surfaces, progress labels, logs, and login surfaces.
- Interactive service cards now use native glass effects while preserving animated edge highlights.
- Input editors and compact status chips now use reusable adaptive glass surfaces.
- macOS 26 remains the minimum supported system version.

### Packaging for this release
- Version: `2.2`
- Build: `04.06.2026.23.13.36`
- Architecture: Apple Silicon only (`arm64`)
- Installer package: `Manga-Downloader-macOS-2.2.pkg`
- Signing: Developer ID Application and Developer ID Installer
- Notarization: accepted and stapled
